**Zed** is a minimal code editor crafted for speed and collaboration with humans and AI, incredibly powerful out of the box, and it only gets better as, every week, there's always a new version.

- **Fast:** written from scratch in Rust to efficiently leverage multiple CPU cores and your GPU.

- **Agentic:** run agents in parallel to smoothly edit files, navigate code, and run tools at native speed.

- **Collaborative:** chat with teammates, code together, and share your screen and project.
