**Android Studio** is the official integrated development environment (IDE) for developing *Android* apps. Built on the code editor and advanced developer tools from *IntelliJ IDEA*, Android Studio adds even more features to boost your productivity when creating *Android* apps, such as:

- A flexible build system based on Gradle

- A fast emulator with numerous features

- A unified environment that enables development for all *Android* devices  

- Live editing to update composable elements on emulators and physical devices  

- Code templates and GitHub integration to help you create common app features and import code examples

- Test frameworks and tools full of possibilities  

- Lint tools to detect performance, usability, version compatibility issues, among others  

- Compatibility with C++ and NDK
